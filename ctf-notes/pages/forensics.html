Forensics

Digital forensics, file analysis, memory dumps, and evidence collection

Cek tipe File

file filename

Untuk mengecek tipe file yang diberikan

forensics file-analysis

Mencari kata/flag

strings filename
strings namafile | grep flag
strings namefile | grep -E '^[A-Za-z0-9+/]{20,}' (untuk mencari base64)
strings namafile | grep -E '^[N-ZA-Mn-za-m]{10,}$' (untuk mencari ROT13)

Untuk mencari kata/flag yang kita cari

forensics reversing

Melihat hexdump menggunakan xxd

xxd filename | head -20
xxd -l 256 filename

menampilkan hexdump/header dari sebuah file.Untuk mengidentifikasi file tersebut rusak/tidak

forensics hex-analysis

Mengecek metadata dari sebuah file

exiftool image.jpg
exiftool -a image.jpg

Mengekstrak metadata dari file yang diberikan

forensics metadata stego

Steganography menggunakan steghide

steghide info image.jpg
steghide extract -sf image.jpg -p password

Mengekstrak file yang disembunyikan, biasanya menggunakan password

forensics stego

Memory Dump Analysis menggunakan Volatility

volatility -f file.raw/mem/dmp/bin imageinfo (untuk mencari imageinfo nya terlebih dahulu)
volatility -f dump.raw --profile=profilefile pslist

Analisis memory dumps running processes, network connections, and artifacts.

forensics memory

Disk Image Analysis with fdisk

fdisk -l disk.img

Melihat partisi apa saja yang ada di dalam file disk tersebut

forensics disk

File Recovery with foremost

foremost -i disk.img -o output/
foremost -i disk.img -t jpg -o output/

Melihat dan Mengekstrak file yang sudah dihapus di dalam disk tersebut

forensics recovery

Hash Calculation

md5sum filename
sha256sum filename
sha1sum filename

Calculate file hashes for integrity verification and comparison. MD5 (deprecated), SHA1, and SHA256 are common algorithms for forensic purposes.

forensics hashing

PDF Analysis with pdftotext

pdftotext file.pdf -
strings file.pdf

Extract text from PDFs or search for hidden content. PDFs can contain metadata, embedded objects, and JavaScript that may contain flags or clues.

forensics document

mount pastisi

mkdir -p /mnt/dir
mount -o ro,loop,offset=$((start*512)) filename /mnt/dir
