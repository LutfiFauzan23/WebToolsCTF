Cryptography

Encryption, decryption, hash cracking, and cryptographic analysis

Hash Identification

hash-identifier
haiti <hash>
hashid '<hash>'

Identify hash types by length and format. Tools like hash-identifier and haiti help determine the hashing algorithm used before attempting to crack.

crypto hashing identification

MD5 Cracking with hashcat

hashcat -m 0 -a 0 hash.txt wordlist.txt
hashcat -m 0 -a 3 hash.txt ?a?a?a?a

Crack MD5 hashes using dictionary attack (-a 0) or brute force (-a 3). The -m flag specifies hash type (0 for MD5). GPU acceleration makes this very fast.

crypto hashing crack

ROT13 Cipher

echo "plaintext" | tr 'A-Za-z' 'N-ZA-Mn-za-m'
# Online: rot13.com

Simple substitution cipher rotating letters by 13 positions. Applying twice returns original text. Quick and easy to decode, often used for obfuscation.

crypto cipher substitution

Caesar Cipher Brute Force

for i in {0..25}; do echo "$((i)): $(echo 'ciphertext' | tr 'A-Za-z' 'N-ZA-Mn-za-m')"; done

Brute force all 26 possible Caesar cipher shifts. Each shift is displayed with its index, making it easy to spot the correct plaintext.

crypto cipher brute-force

Base64 Encoding/Decoding

echo "plaintext" | base64
echo "cGxhaW50ZXh0Cg==" | base64 -d

Encode text to base64 or decode base64 strings. Base64 is commonly used for obfuscation and data transmission, not true encryption.

crypto encoding base64

OpenSSL Encryption

openssl enc -aes-256-cbc -in file.txt -out file.enc -K key -iv iv
openssl enc -aes-256-cbc -d -in file.enc -out file.txt -K key -iv iv

Encrypt and decrypt files using AES-256-CBC. Provides symmetric encryption with specified key and initialization vector. Useful for cryptographic challenges.

crypto encryption aes

RSA Key Analysis

openssl rsa -in key.pem -text -noout
openssl rsa -pubin -in pubkey.pem -text -noout

Examine RSA key components including modulus, exponent, and prime factors. Useful for identifying weak keys or extracting public information for cryptanalysis.

crypto rsa key-analysis

Hex to ASCII Conversion

echo "48656c6c6f" | xxd -r -p
printf '\x48\x65\x6c\x6c\x6f\n'
echo "48656c6c6f" | sed 's/../\\x&/g' | xargs printf

Convert hexadecimal strings to ASCII text. Multiple methods available: xxd, printf, and sed. Essential for decoding encoded messages.

crypto encoding conversion

XOR Brute Force

python3 -c "
for key in range(256):
    print(bytes([b ^ key for b in bytes.fromhex('hex_string')]))
"

Brute force single-byte XOR cipher by trying all 256 possible keys. Python loops through each key and outputs the result for manual inspection.

crypto xor brute-force
