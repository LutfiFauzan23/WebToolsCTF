OSINT

Open Source Intelligence - Reconnaissance and information gathering

Whois Lookup

whois example.com

Retrieve WHOIS information for a domain including registrar, registration date, and contact details. Useful for gathering passive reconnaissance data on targets.

recon osint domain

DNS Enumeration with dig

dig example.com @8.8.8.8
dig example.com MX
dig example.com NS

Perform DNS lookups to find mail servers, nameservers, and other DNS records. The @8.8.8.8 flag queries Google's DNS, while MX and NS queries specific record types.

recon dns osint

Zone Transfer (AXFR)

dig @ns.example.com example.com AXFR

Attempt a zone transfer to retrieve all DNS records from a nameserver. This can expose internal infrastructure and subdomains. Often restricted on production systems.

recon dns zone-transfer

Port Scanning with Nmap

nmap -sV example.com
nmap -p- -sV example.com
nmap -sC -sV example.com

Scan for open ports and identify services. -sV detects versions, -p- scans all ports, and -sC runs default scripts. Essential for network reconnaissance.

recon nmap portscan

Subdomain Enumeration with amass

amass enum -d example.com
amass enum -d example.com -v

Discover subdomains using passive and active reconnaissance techniques. The -v flag enables verbose output showing more detailed information.

recon subdomain osint

Reverse IP Lookup

nslookup -query=PTR 1.2.3.4

Perform reverse DNS lookups to find hostnames associated with an IP address. Useful for identifying virtual hosts and hidden services.

recon dns osint

Web Crawler with curl

curl -I example.com
curl -L example.com

Fetch headers (-I) or follow redirects (-L) to gather information about web servers. Headers often reveal server type, CMS, and other technologies in use.

recon web osint

Google Dorks

site:example.com filetype:pdf
site:example.com inurl:admin
site:example.com "username"

Use advanced Google search operators to find sensitive files, pages, and information indexed by search engines. Powerful technique for passive reconnaissance.

osint google-dorks passive

Email Finder

hunter.io
rocketreach.co
clearbit.com

Online tools for finding email addresses associated with a domain. Useful for social engineering reconnaissance and identifying key personnel.

osint email recon

Metadata Extraction with exiftool

exiftool image.jpg
exiftool -a image.jpg

Extract metadata from files including images, documents, and videos. Can reveal GPS coordinates, camera info, software versions, and author details.

osint metadata forensics
