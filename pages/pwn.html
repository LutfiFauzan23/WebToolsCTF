PWN

Binary exploitation, buffer overflows, shellcode, and ROP chains

Check Binary Protections

checksec --file=binary
file binary
ldd binary

Analyze binary security features like ASLR, DEP/NX, stack canaries, and PIE. Checksec provides a comprehensive overview. Ldd shows required libraries and addresses.

pwn binary analysis

Disassemble with objdump

objdump -d binary
objdump -d -M intel binary
objdump -t binary | grep system

Disassemble binary code to analyze functions. The -M intel flag uses Intel syntax instead of AT&T. Grep for interesting functions like system, exec, or main.

pwn disassembly analysis

GDB Debugging

gdb ./binary
run <args>
break *0x400000
continue
step
info registers

Use GDB for interactive debugging. Set breakpoints, step through code, inspect memory and registers. Essential for understanding program flow and exploitation.

pwn debugging gdb

Buffer Overflow Detection

python3 -c "print('A'*100)" | ./binary
gdb -ex "run <<< $(python3 -c 'print(\"A\"*100)')" ./binary

Test for buffer overflow vulnerabilities by sending large input. Monitor for segmentation faults or crashes indicating memory corruption.

pwn overflow testing

Shellcode Generation with msfvenom

msfvenom -p linux/x86/shell_bind_tcp -f python
msfvenom -p linux/x64/exec CMD=/bin/bash -f elf

Generate shellcode payloads for various architectures. The -f flag specifies output format (python, hex, elf, etc.). Useful for payload development.

pwn shellcode payload

Pwntools - Python Exploitation Library

from pwn import *
p = process('./binary')
p.sendline(b'payload')
p.recvline()

Pwntools simplifies exploitation with convenient functions for process interaction, payloads, and assembly. Essential library for modern CTF pwning.

pwn python tool

Return-Oriented Programming (ROP)

ropper --file binary
ROPgadget --binary binary --ropchain

Find ROP gadgets to build chains when shellcode execution is restricted. Ropper and ROPgadget automatically search for useful gadgets and generate chains.

pwn rop gadgets

ASLR Bypass

ldd binary | grep libc
# Leak address via infoleak
# Calculate offset from leak

Address Space Layout Randomization can be bypassed using information leaks. Read addresses from memory, calculate offsets, then exploit with known libc functions.

pwn aslr bypass

Format String Vulnerability

%x.%x.%x.%x
%n - write
%s - read

Format string bugs occur when user input is passed directly to printf. %x leaks stack values, %s reads memory, %n writes to memory. Powerful exploitation primitive.

pwn format-string vulnerability

Stack Canary Leaking

gdb -ex "break main" -ex "run" ./binary
gdb> x/wx $rsp+offset

Stack canaries protect against buffer overflows. Leak the canary value first using format strings or information disclosure, then overwrite it during exploitation.

pwn canary protection
