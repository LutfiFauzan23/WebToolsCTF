Reverse Engineering

Decompilation, disassembly, binary analysis, and software cracking

File Type Detection

file binary
file -b binary
readelf -h binary

Identify binary type and architecture. File command shows basic info, readelf displays ELF header details. Essential first step in reverse engineering.

reversing analysis binary

Strings Extraction

strings binary
strings -n 10 binary
strings binary | grep -i flag

Extract printable strings from binary files. Often reveals hardcoded strings, URLs, file paths, or even flags. Quick reconnaissance technique.

reversing strings recon

Disassembly with objdump

objdump -d binary | head -50
objdump -d -M intel binary
objdump -S binary

Disassemble binary code to assembly language. Intel syntax is more readable. -S shows source code if debug symbols are present.

reversing disassembly asm

IDA Pro / Ghidra Disassembler

ghidra &
# Load binary and analyze
# View decompiled code

Professional-grade disassemblers with decompilation. Ghidra is free and open-source. IDA Pro is industry standard. Both provide GUI for easier analysis.

reversing decompilation tool

Hex Editor Analysis

hexdump -C binary
xxd binary
xxd -l 256 binary

View raw hexadecimal content of binaries. Helps identify magic bytes, data sections, and embedded files. -C and xxd show both hex and ASCII.

reversing hex binary

Symbol Table Analysis

nm binary
nm -D binary
readelf -s binary

Extract function and variable names from binaries. Dynamic symbols (-D) show functions used at runtime. Debug symbols provide even more information.

reversing symbols analysis

Decompiling Java with CFR

cfr program.jar
cfr program.jar --outputdir src/

Decompile Java .class files and JAR archives back to source code. CFR is modern and handles advanced Java features well.

reversing java decompilation

Python Bytecode Decompilation

uncompyle6 program.pyc
decompyle3 program.pyc

Reverse Python .pyc compiled files back to Python source. Useful for analyzing compiled Python applications and finding embedded logic.

reversing python decompilation

APK Analysis (Android)

apktool d app.apk
dex2jar app.dex
cfr app.jar

Analyze Android APK files. Apktool extracts and decompiles resources. Dex2jar converts DEX to JAR, then CFR decompiles to Java source.

reversing android apk

GDB Interactive Debugging

gdb ./binary
(gdb) break main
(gdb) run
(gdb) disassemble main
(gdb) info registers

Step through binary execution with full control. Set breakpoints, inspect memory, view registers. Critical for understanding program behavior at runtime.

reversing debugging gdb

License String Cracking

strings binary | grep -i license
strings binary | grep -E "^[A-Z0-9]{16,}"

Search for hardcoded license keys or validation strings. License checks are often found as plaintext in compiled code or simple transformations.

reversing cracking license
